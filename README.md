# KK AI Chat

A modern AI chatbot powered by GLM-4.

Features

✅ Streaming Response

✅ Long-term Memory

✅ Markdown Rendering

✅ Code Highlight

✅ Copy Code

✅ Chat History

✅ SQLite Storage

✅ FastAPI Backend
